## Таблица Пинов ESP32

| Назначение     | Пин GPIO | Тип        | Назначение                          |
| -------------- | -------- | ---------- | ----------------------------------- |
| ESC Motor 1    | GPIO-25  | PWM Output | Передний левый мотор                |
| ESC Motor 2    | GPIO-26  | PWM Output | Передний правый мотор               |
| ESC Motor 3    | GPIO-27  | PWM Output | Задний правый мотор                 |
| ESC Motor 4    | GPIO-14  | PWM Output | Задний левый мотор                  |
| MPU-6050 SDA   | GPIO-21  | I2C        | Шина данных I2C                     |
| MPU-6050 SCL   | GPIO-22  | I2C        | Шина часов I2C                      |
| Power Input    | VIN      | Power      | 5V от DC-DC преобразователя         |
| Ground         | GND      | Power      | Общая земля                         |
| MPU-6050 Power | 3.3V     | Power      | Питание датчика от регулятора ESP32 |

## Конденсаторы Фильтрации

| Компонент         | Значение      | Место установки           |
| ----------------- | ------------- | ------------------------- |
| Электролитический | 100 мкФ × 16V | Параллельно выходу LM2596 |
| Керамический      | 100 нФ        | У выводов VIN ESP32       |

## Конфигурация Моторов (X-конфигурация)

```
       ↑ Направление полёта

      M1 ──────── M2
      (Л)        (П)
       \         /
        \       /
         \     /
          \   /
           ESP32

           / \
          /   \
         /     \
        /       \
      M4 ──────── M3
      (Л)        (П)

Л = Левый, П = Правый
M1 = Передний левый
M2 = Передний правый
M3 = Задний правый
M4 = Задний левый
```

## Блок-схема Управления

```
┌──────────────────┐
│   MPU-6050       │
│  (Гироскоп +     │
│  Акселерометр)   │
└────────┬─────────┘
         │ I2C (GPIO-21/22)
         ▼
┌──────────────────────────────────┐
│   ESP32 DevKit                   │
│  ┌──────────────────────────────┐│
│  │ 1. Чтение IMU данных         ││
│  │ 2. Фильтр Дополнительности   ││
│  │    (Complementary Filter)    ││
│  │ 3. Вычисление углов          ││
│  │    (Roll, Pitch, Yaw)        ││
│  │ 4. PID Контроллер            ││
│  │ 5. Распределение тяги на ESC ││
│  └──────────────────────────────┘│
└────────┬─────────────────────────┘
         │ PWM сигналы (GPIO-25,26,27,14)
         ▼
┌────────┴──────────────────────────┐
│                                   │
▼                                   ▼
ESC (Electronic Speed Controller) × 4
│
▼
Motor × 4
```

## Параметры PWM

- **Частота**: 50 Hz (период 20 ms)
- **Разрешение**: 8-bit (0-255)
- **Минимум**: ~125 (throttle off)
- **Максимум**: ~255 (full throttle)
- **Нейтраль**: 125

## Питание Системы

```
3S Li-Po (11.1V-12.6V)
    │
    ├─→ PDB ─→ 4× ESC ─→ 4× Motor
    │
    └─→ LM2596 (12V→5V) ─→ ESP32 VIN
                              │
                              ├─→ 3.3V Regulator ─→ MPU-6050
                              │
                              └─→ 100µF + 100nF Filter Caps
```

## Расстояния между Моторами (F450)

- Размах (Wheelbase): 450 мм
- Расстояние между центрами моторов:
  - Передняя ось: 320 мм
  - Боковая ось: 320 мм
